## 1. Explain the difference between Frontend, Backend, and Full-Stack Development with suitable real-world examples.

### Frontend Development

Frontend development focuses on the part of a website or web application that users can see and interact with. It includes designing layouts, buttons, forms, navigation menus, and animations. Frontend developers mainly use HTML, CSS, and JavaScript along with frameworks such as React or Angular.

**Real-world example:**
On Amazon, the product images, search bar, shopping cart icon, and product descriptions that users interact with are all part of the frontend.

### Backend Development

Backend development is responsible for the server-side logic that users cannot see. It manages business logic, user authentication, database operations, and communication between the frontend and the database. Common backend technologies include Java, Python, Node.js, PHP, and databases like MySQL and MongoDB.

**Real-world example:**
When a customer places an order on Amazon, the backend verifies payment, updates inventory, stores order details, and sends confirmation emails.

### Full-Stack Development

A full-stack developer works on both the frontend and backend of a web application. They build user interfaces as well as server-side functionality and database integration.

**Real-world example:**
A full-stack developer creating an online food delivery website would design the ordering interface, develop the backend APIs, and connect the application to the database.

## 3. Describe how a browser requests and displays a web page from a web server.

When a user enters a website address (URL) into a browser, the browser first contacts the Domain Name System (DNS) to find the website's IP address. After finding the IP address, the browser sends an HTTP or HTTPS request to the web server. The server processes the request and, if required, retrieves information from a database. It then sends back HTML, CSS, JavaScript, images, and other resources. The browser downloads these files, creates the Document Object Model (DOM), applies CSS styles, executes JavaScript, and finally displays the complete web page on the screen.

## 5. Explain what a web server is and give examples of commonly used servers.

A web server is software or hardware that receives requests from users through a web browser and responds by sending web pages or data using the HTTP or HTTPS protocol. It stores website files, processes requests, and delivers content to users.

### Examples of Web Servers

* Apache HTTP Server
* Nginx
* Microsoft IIS
* LiteSpeed
* Caddy

## 9. Research and list five web browsers. Explain how rendering engines differ between them.

| Browser         | Rendering Engine |
| --------------- | ---------------- |
| Google Chrome   | Blink            |
| Microsoft Edge  | Blink            |
| Mozilla Firefox | Gecko            |
| Apple Safari    | WebKit           |
| Opera           | Blink            |

### Rendering Engines

A rendering engine converts HTML, CSS, and JavaScript into the web pages users see on their screens.

* **Blink** is designed for speed and performance.
* **Gecko** focuses on web standards and flexibility.
* **WebKit** is optimized for Apple devices and efficient power usage.

Different rendering engines may display the same webpage with slight differences because each engine processes web technologies differently.
