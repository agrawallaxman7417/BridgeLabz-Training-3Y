# Assignment 10 — Bootstrap 5 Solutions

10 separate questions are provided in Q1–Q10. Each folder contains:
- index.html
- style.css

All pages use Bootstrap 5 via CDN. Q6 and Q10 include Bootstrap's JavaScript bundle because dismissible alerts and carousel require Bootstrap JS.

Open any `index.html` in a browser. Internet access is required for Bootstrap CDN, Google Fonts, and remote Unsplash images.
