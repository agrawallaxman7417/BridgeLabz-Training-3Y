Responsive CSS Cheat Sheet

Filters

Modify visual appearance using CSS filters.

filter: grayscale(100%);

Media Queries

Apply styles at specific viewport sizes.

@media (max-width: 700px)

Responsive Design

Build layouts that adapt to available space.

width: 100%; max-width: 1200px;

Typography

Use relative sizes for readable text.

font-size: clamp(1rem, 2vw, 1.5rem);
